# AdaptIQ

AdaptIQ is an adaptive assessment platform built on the MERN stack. The core philosophy is to provide "Quizzes that get harder exactly when you're ready," adjusting dynamically to the learner's skill level.

## Overview
The platform serves three main personas:
1. **Student**: Take adaptive assessments, track mastery, and earn certificates.
2. **Teacher**: Manage classes, assign quizzes, and monitor student performance.
3. **Interviewer**: Create role-specific assessments and evaluate candidates.

## Technology Stack
- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose)
